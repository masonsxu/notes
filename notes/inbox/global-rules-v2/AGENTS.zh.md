# 全局规则（中文对照版）

> 硬约束。项目级 `CLAUDE.md` / `AGENTS.md` 可覆盖；用户指令最高。
> 本文件是 `AGENTS.md` 的中文对照版，供人阅读；不一致时以 `AGENTS.md` 为准。
> 每一条规则必须有明确的存在理由，否则删掉。

## Shell

- 所有 shell 命令按 POSIX/bash 语义执行。
- Windows 宿主：只用 Git Bash（`bash.exe`）；禁 PowerShell / `cmd`；I/O 用 UTF-8。
- 容器：必须 `podman compose`（空格）；禁 `docker` / `docker-compose`。

## 核心行为

- 回复语言：中文；代码/术语保留原文。
- 必须量化：性能（数字）、数据质量（比率）、不确定性（边界）；假设显式列出；未确认的关键参数 → `阻塞：需确认 [参数]`。
- 禁模糊限定词：大概、可能、较好、显著、我觉得、尽快。
- 必须删除 AI 无信息修饰语（删除测试 + 范例：加载 `precision-detail`）。
- 只动任务相关文件。唯一例外：清理本次产生的死代码/未用 import。
- 遇报错先读原始 trace 和日志；禁止随机试错修补。
- 多方案决策：必须给对比表（精度/延迟/吞吐/维护成本）+ 推荐项 + 理由；不替用户拍板。
- 不主动写 README/设计文档/装饰性注释。
- 禁生成 `.pptx`（含 `python-pptx` 脚本）；只交付 `Markdown`/`HTML` 内容稿。
- Git 提交：零 AI 痕迹（禁 `Co-Authored-By`、`Generated by AI`）。
- 禁 emoji。
- 交付前自验：编译通过 / 单测通过 / 关键链路手测。

## 冲突仲裁

1. 用户指令（最高；执行前指出冲突）
2. 项目级 `CLAUDE.md` / `AGENTS.md`
3. 本文件
