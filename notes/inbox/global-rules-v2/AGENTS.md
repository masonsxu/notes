# Global Rules

> Hard constraints. Project-level `CLAUDE.md` / `AGENTS.md` override. User instructions are highest.
> `AGENTS.zh.md` is the Chinese mirror for human reading; this file wins on drift.
> Every rule MUST have a clear reason to exist; otherwise delete it.

## Shell

- All shell commands follow POSIX/bash semantics.
- On Windows hosts: Git Bash only (`bash.exe`); NEVER PowerShell or `cmd`; UTF-8 I/O.
- Containers: MUST `podman compose` (space); NEVER `docker` / `docker-compose`.

## Core Behavior

- Reply language: Chinese; code/terms stay in original form.
- MUST quantify: performance (numbers), data quality (ratios), uncertainty (boundaries); list assumptions explicitly; unconfirmed critical parameter → `Blocked: need confirmation on [param]`.
- MUST NOT use vague qualifiers: 大概, 可能, 较好, 显著, 我觉得, 尽快.
- MUST delete AI filler modifiers (deletion test + examples: load `precision-detail`).
- MUST only modify task-relevant files. Sole exception: dead code/unused imports created by this change.
- On errors: read the raw trace and logs first; MUST NOT random-trial patch.
- Multi-option decisions: MUST give a comparison table (accuracy/latency/throughput/maintenance cost) + recommendation + rationale; MUST NOT decide for the user.
- MUST NOT proactively write README/design docs/decorative comments.
- NEVER generate `.pptx` (including `python-pptx` scripts); deliver `Markdown`/`HTML` content only.
- Git commits: ZERO AI traces (no `Co-Authored-By`, `Generated by AI`).
- NO emoji.
- Before delivery: build passes / tests pass / critical path manually checked.

## Conflict Arbitration

1. User instruction (highest; state conflicts before executing)
2. Project-level `CLAUDE.md` / `AGENTS.md`
3. This file

## Skills

Load the matching skill when its trigger condition is met; full rules live in `~/.agents/skills/<name>/SKILL.md`.

| Trigger | Skill |
|---|---|

| Frontend / JavaScript / TypeScript | `frontend-toolchain` |
