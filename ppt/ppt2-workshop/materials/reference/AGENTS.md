# 角色与背景

我是测试部门的工程师，负责接触电阻（rc）数据的周期分析。本项目用于每周批次的统计与报告：数据落在 `data/`，图表在 `assets/`，报告在 `reports/`，模板在 `templates/`。

# 术语解释

- rc_mohm：接触电阻，单位毫欧（mΩ）
- batch / 批次：同一周投产的一组晶圆，标签形如 w31
- wafer / 晶圆：wafer_id 形如 w31-01，每批次 3 片
- die：晶圆上的测试单元，位置由 die_x、die_y（0–9）确定，每片 100 个
- 边缘 die：die_x 或 die_y 取 0 或 9 的单元
- CPK：单边上限过程能力指数，(USL − 均值) / (3 × 标准差)，USL = 50 mΩ

# 常用文件 / 命令

- `data/rc_*.csv`：原始数据，列为 batch, wafer_id, die_x, die_y, rc_mohm
- 统计用 python；输出中文 Markdown 表格，报告按 `templates/rc-weekly.md` 结构生成

# 注意事项（口径与红线）

- 原始数据只读：任何清理都在内存或新文件里完成，不改动 `data/` 原文件
- USL 50 mΩ；CPK 低于 1.33 的批次必须标注 ⚠ 并在报告置顶
- 边缘 die 异常单独列一节，不计入批次失败判定
- 读入数据必须校验行数与数值列，任何一行异常要报告，不许静默跳过
- 历史坑：w32 的导出文件中间混入一行重复表头（文件 301 行），读入后先剔除再统计（2026-08 工作坊沉淀）
- 每条结论必须附支撑数字
